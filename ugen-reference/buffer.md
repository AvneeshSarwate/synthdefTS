### BufRd — Buffer reading oscillator.
- `BufRd.ar({ numChannels, bufnum=0, phase=0, loop=1, interpolation=2 })`
- `BufRd.kr({ numChannels, bufnum=0, phase=0, loop=1, interpolation=2 })`

> Read the content of a buffer at an index. In comparison to PlayBuf : PlayBuf plays through the buffer by itself, BufRd only moves its read point by the phase input and therefore has no pitch input. BufRd has variable interpolation.

- `BufWr.kr({ inputArray, bufnum=0, phase=0, loop=1 })`

> Write to a buffer at an index. BufWr (in difference to BufRd) does not do multichannel expansion, because input is an array. ::

### Dbufrd — Buffer read demand ugen
- `Dbufrd.new({ bufnum=0, phase=0, loop=1 })`

> On each demand trigger, reads channel 0 only from a buffer at an integer-truncated (no interpolation) phase index. With loop=1, phase wraps modulo bufFrames; with loop=0, phase clamps to [0, bufFrames-1] and sets mDone=true. NaN from the phase input is passed straight to the output.

### Dbufwr — Buffer write demand ugen
- `Dbufwr.new({ input=0, bufnum=0, phase=0, loop=1 })`

> On each demand tick, reads the phase input, applies sc_loop (wrap if loop=1, clamp+done if loop=0), truncates to int frame index, and writes the value to channel 0 of that buffer slot; the written value passes through as output. NaN on phase or value propagates NaN immediately, ending the sequence.

### DelTapRd — Tap a delay line from a DelTapWr UGen
- `DelTapRd.ar({ buffer, phase, delTime, interp=1, mul=1, add=0 })`
- `DelTapRd.kr({ buffer, phase, delTime, interp=1, mul=1, add=0 })`

> Tap a delay line from a DelTapWr UGen. If you run a DelTapRd.ar and a DelTapWr.ar in tandem, keep in mind that they read and write in blocks equal to the server's block size. If the delay time is greater than the buffer size minus a block, the write and read heads might interfere in unintended ways. Use a slightly larger buffer if this happens.::

### DetectIndex — Search a buffer for a value
- `DetectIndex.ar({ bufnum, in=0, mul=1, add=0 })`
- `DetectIndex.kr({ bufnum, in=0, mul=1, add=0 })`

> Linearly searches a buffer for a value (i.e., loops over the frames in the buffer from the beginning, checking for float equality), and returns index of first occurrence of said value. Returns -1 if value is not found. The object performs a search whenever a change in the in argument is detected; changes in the bufnum argument do not trigger searches. Checks for changes occur at the selected rate (ar or kr).

### GrainBuf — Granular synthesis with sound stored in a buffer
- `GrainBuf.ar({ numChannels=1, trigger=0, dur=1, sndbuf, rate=1, pos=0, interp=2, pan=0, envbufnum=-1, maxGrains=512, mul=1, add=0 })`

> On each trigger, a grain is spawned that reads a mono buffer starting at phase = pos * bufFrames, advancing each sample by rate * bufSampleRate * SAMPLEDUR (so rate=1.0 reproduces the buffer's native pitch regardless of server rate). The internal Hann envelope is generated by a squared-sine second-order IIR resonator: b1 = 2·cos(π/N), seeded with y1=sin(π/N), y2=0, then y0 = b1·y1 − y2; y2 = y1; y1 = y0; amp = y1², where N is grain duration in samples (clamped to ≥ 4). Custom envelopes (winType ≥ 0) linearly interpolate a user buffer at stride windowSamples/N per sample. Interpolation is selectable per-grain (1=nearest, 2=linear, 4=cubic); multichannel output uses constant-power cos/sin panning across adjacent channel pairs, with the channel assignment frozen at grain spawn. New grains are silently dropped once mNumActive reaches maxGrains, with no warning to the audio thread beyond a Print call.

### Index — Index into a table with a signal
- `Index.ar({ bufnum, in=0, mul=1, add=0 })`
- `Index.kr({ bufnum, in=0, mul=1, add=0 })`

> Index into a table with a signal. The input signal value is truncated to an integer value and used as an index into the table. Out-of-range index values are clipped to the valid range.

### IndexInBetween — Finds the (lowest) point in the Buffer at which the input signal lies in-between the two values
- `IndexInBetween.ar({ bufnum, in=0, mul=1, add=0 })`
- `IndexInBetween.kr({ bufnum, in=0, mul=1, add=0 })`

> Finds the (lowest) point in the Buffer at which the input signal lies in-between the two values, and returns the index. The fractional part of the index is suitable for linearly interpolating between the buffer slot values. For example, if the Buffer contains [3, 21, 25, 26] and the input has the value 22, then the output will be 1.25, because the value 22 is in-between the values stored in indices 1 and 2 and in fact is one-quarter of the way along the interval between them. IndexInBetween is the complement of IndexL.

### PlayBuf — Sample playback oscillator.
- `PlayBuf.ar({ numChannels, bufnum=0, rate=1, trigger=1, startPos=0, loop=0, doneAction=0 })`
- `PlayBuf.kr({ numChannels, bufnum=0, rate=1, trigger=1, startPos=0, loop=0, doneAction=0 })`

> Reads a server-resident buffer via a double-precision phase accumulator incremented each sample by rate (frames/sample; 1.0 = original pitch, negative = reverse). Output uses 4-point, 3rd-order Hermite interpolation (x-form): cubicinterp(frac, x[n-1], x[n], x[n+1], x[n+2]), with boundary table pointers replicated (non-loop) or wrapped (loop) to stay in-bounds. With loop=0, sc_loop sets mDone when phase >= bufFrames-1 (forward) or phase < 0 (reverse) and clamps phase to that boundary; doneAction fires after the block. With loop=1, loopMax = bufFrames and sc_loop wraps modulo bufFrames, using floor(in/hi) for multi-period overshoots. The trig input retriggers only on a positive-going zero crossing (prevtrig<=0 to trig>0), resetting phase to startPos; a held-high trig will not re-trigger until it goes low first.

### RecordBuf — Record or overdub into a Buffer.
- `RecordBuf.ar({ inputArray, bufnum=0, offset=0, recLevel=1, preLevel=0, run=1, loop=1, trigger=1, doneAction=0 })`
- `RecordBuf.kr({ inputArray, bufnum=0, offset=0, recLevel=1, preLevel=0, run=1, loop=1, trigger=1, doneAction=0 })`

> Records input into a Buffer. If recLevel is 1.0 and preLevel is 0.0 then the new input overwrites the old data. If they are both 1.0 then the new data is added to the existing data. (Any other settings are also valid.) The number of channels must be fixed for the SynthDef, it cannot vary depending on which buffer you use. ::

### Tap — Single tap into a delay line
- `Tap.ar({ bufnum=0, numChannels=1, delaytime=0.2 })`

> A pure-SC wrapper around PlayBuf with no C++ backend. At SynthDef compile time it computes a fixed read offset n = delaytime * (SampleRate.ir.neg * BufRateScale.kr(bufnum)) frames, then calls PlayBuf.ar with rate=BufRateScale.kr(bufnum), trigger=0, startPos=n, loop=1; the negative startPos wraps modulo bufFrames under looping, placing the read head exactly delaytime seconds behind the write head (assuming both start in sync, as in the BufWr+Phasor idiom). Because delaytime is a compile-time SC literal rather than a modulatable UGen input, it is baked in at build time — changing it requires freeing and rebuilding the SynthDef. BufRateScale compensation keeps the tap tempo-correct when the buffer's native sample rate differs from the server rate, but if the buffer is smaller than delaytime * sampleRate frames the startPos wrap lands at the wrong phase and the effective delay is buffer-length-modulo, not the requested value.

### TGrains — Buffer granulator.
- `TGrains.ar({ numChannels, trigger=0, bufnum=0, rate=1, centerPos=0, dur=0.1, pan=0, amp=0.1, interp=4 })`

> Triggers generate grains from a buffer. Each grain has a Hanning envelope (sin2(x) for x from 0 to π) and can be panned over multichannel output.

### Warp1 — Warp a buffer with a time pointer
- `Warp1.ar({ numChannels=1, bufnum=0, pointer=0, freqScale=1, windowSize=0.2, envbufnum=-1, overlaps=8, windowRandRatio=0, interp=1, mul=1, add=0 })`

> Inspired by Chad Kirby's SuperCollider2 Warp1 class, which was inspired by Richard Karpen's sndwarp for CSound. A granular time stretcher and pitchshifter.
